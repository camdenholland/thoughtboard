# Magic UI Particles

`src/Particles.tsx` is adapted from https://github.com/magicuidesign/magicui/blob/main/apps/www/registry/magicui/particles.tsx (retrieved October 19, 2026). Documentation: https://magicui.design/docs/components/particles.

Changes: plain CSS integration, sage color configuration, reduced-motion support, pause while hidden, capped pixel density, responsive particle count, resize observation, and removal of duplicate particle initialization.
